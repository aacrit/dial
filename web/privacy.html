Privacy

What stays on your device

When a work is made on your device, the narration is made in your browser tab. The voice, its runtime and the text are downloaded from this site, and the recording is made from them on your device. The words and the audio are never sent anywhere; the only things this page sends are the daily counts and any feedback you choose to send, described below. The voice is kept in your browser's cache storage so it downloads only once; clearing this site's data removes it.

How fast your device makes speech is measured in your browser tab, from the lines it makes and, where you choose to test your graphics chip, from one short sentence. The speed test's results are shown on the radio and never sent, not even as a count. Testing the graphics chip downloads a second copy of the voice from this site, its size shown before you choose; it is kept in cache storage like the first, and deleted again if the graphics chip does not make speech faster than the processor.

Recordings Dial made in advance

A work with a recording Dial made in advance plays that recording. It is downloaded from this site, a part at a time as you listen, and Dial keeps it in its own storage only if you save the work for offline. Nothing is made on your device while it plays, and the words and the audio are never sent anywhere. Once you have heard four fifths of a work, one listen is counted (see what this site counts, below).

Saved for offline

"Save for offline" keeps a work's text, the voice it needs and this site's own page files in your browser's cache storage on this device, so the work plays with no connection. For a work with a recording Dial made in advance, it keeps that recording instead of the voice. Saving only downloads this site's own files: nothing about what you save is sent. An offline helper (a service worker) hands those files to the page when there is no connection. It never stores the daily counts or feedback, and it sends nothing of its own. It tells Dial's open pages which requests it made, on this device only, so the Seal widget on the radio can list them.

Remove deletes that work's text, its saved recording, and any voice no other saved work uses. The voice model stays, because every work uses it; clearing this site's data removes everything. On the first save, Dial asks the browser to keep saved works (persistent storage); if the browser declines, it may clear them when the device runs short of space. On iPhone and iPad, in a Safari tab, saved works can be cleared if you do not open Dial for a week.

The offline helper also keeps this site's page files (about 0.6 MB: the pages, their main script and styles, the fonts' Latin faces and the icons) in cache storage for every visitor, whether or not anything is saved, so the pages open with no connection. When you save a work it keeps the rest of the page files too (about 2.5 MB more, mostly the script that makes speech on this device). The voice model and its runtime stay after the last Remove, as they do after any listen; clearing this site's data removes them.

If you choose "Not now" on the card that offers to install Dial, that date is kept in the same cache storage so the card stays hidden for 30 days. It is never sent.

What this site counts

Dial counts how many times a small set of named events happen each day, such as a page view, a work chosen on the dial, or a completed action, as totals. It does not record who did what, when a specific visit happened, or anything else that could identify you. There is no anonymous id, no cookie, and no third-party analytics script.

You can turn the counts off in the Seal widget on the radio, with the switch "Send anonymous counts". When it is off, this site sends no counts at all: no page view, no work tuned in and no listen (a work heard for at least four fifths of its length, made on this device or Dial's recording). A feedback message you choose to send still goes, because you sent it. The Seal widget itself sends nothing and counts nothing. If your browser will not let Dial keep the setting, the Seal widget disables the switch and says so; counts stay as they were.

The feedback form sends the text you type and the page you sent it from; the server stores them with the time the message arrived. Nothing else is attached to it. Please do not include your name, email, or other personal details in a feedback message.

What Dial keeps in your browser

Besides the voice, saved works and page files described above, Dial keeps four small things, all on your device and never sent. The counts switch: one setting in local storage, whether to send daily counts, written only when you change it. Which encoding of Dial's prepared recording plays in this browser: one setting in local storage, written only once trying the usual one fails, so it is not tried again. This device's speed: one setting in local storage, which engine (processor or graphics chip) made speech faster and how fast, written when a work is made on this device, so the speed test runs once. This tab's request log: the path, size and time of each request Dial's pages and their voice helpers made in this tab, of each request the offline helper made for this tab, and, marked as shared, of what the offline helper fetched for itself for every Dial tab (and, for a count, its name, and whether a send was not delivered), kept in session storage so the Seal widget on the radio can show it; never any text or audio, and erased when the tab closes.

Your connection

Every page, script, style and font comes from this site; nothing is loaded from another company. To stop abuse, the server limits how many requests one network can make in a short time. For that it uses your IP address (for an IPv6 address, only its network part) while answering the request: Cloudflare keeps a short-lived count in memory, and Dial never stores or logs the address. Dial keeps no log of ordinary requests: Cloudflare's per-request logs are turned off for this site, and Dial's own code logs nothing about who asked or what was sent. Cloudflare, which hosts the site, still handles your IP address to deliver it, as any host does.

One exception: if one IP address sends more than 30 requests to voidvision.org sites in 10 seconds, Cloudflare's firewall blocks it for 10 seconds and records each blocked request (the IP address, the page asked for and the browser's user agent) in the site's security event log, which Cloudflare keeps for a limited time. That log is used only to see and stop abuse.

Retention

Daily event totals are kept indefinitely: a total identifies no one, so there is nothing in it to delete. Feedback text is kept for 90 days, then deleted automatically in batches on days the site is used. If the site goes unvisited for a while, deletion falls behind and catches up once visits resume. Cloudflare D1, the database Dial uses, can restore itself to any moment in the last 7 days, so deleted feedback can remain in that restore window for up to 7 more days.

Deletion

Feedback text you sent can be deleted early on request, if you can describe it well enough to find (for example, the page and roughly when you sent it). Use the feedback form on the home page to ask.
